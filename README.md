# سامانه مدیریت تعمیرگاه تخصصی موبایل و تجهیزات الکترونیکی

نرم‌افزار مدیریت تعمیرگاه، چندکاربره و کاملاً آفلاین برای شبکه داخلی (LAN).
مرحله ۱ (زیرساخت، معماری و سیستم امنیتی) پیاده‌سازی و آزمایش شده است.

## فناوری‌ها

| بخش | فناوری |
| --- | --- |
| رابط کاربری | React ۱۹ + TypeScript + Vite + Tailwind CSS ۴ (فارسی، RTL، تقویم هجری شمسی) |
| سرور | Node.js ۲۲+ و NestJS ۱۱ (REST API) |
| پایگاه داده | PostgreSQL ۱۸ (مهاجرت‌های افزایشی SQL) |
| احراز هویت | JWT کوتاه‌عمر + نشست چرخشی با کوکی HttpOnly |
| قفل خودکار | تشخیص بی‌کاری در کلاینت + بازکردن با رمز از طریق سرور |

مستندات: [معماری](docs/ARCHITECTURE.md) — [پایگاه داده](docs/DATABASE.md) — [استقرار](docs/DEPLOYMENT.md) — [گزارش مرحله ۱](docs/PHASE-1-REPORT.md)

## اجرای سریع (توسعه)

پیش‌نیاز: Node.js ۲۲ یا جدیدتر و یک پایگاه داده PostgreSQL.

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) تنظیمات سرور را بسازید و مقادیر DATABASE_URL و JWT_SECRET را ویرایش کنید
cp server/.env.example server/.env

# ۳) پایگاه داده را بالا بیاورید (یکی از دو روش)
npm run db:up            # با Docker
# یا: node scripts/dev-db.mjs   # PostgreSQL محلی برای توسعه، بدون نیاز به Docker

# ۴) ساخت رابط کاربری و اجرای سرور روی پورت ۳۰۰۰
npm run build
npm start
```

سپس در مرورگر `http://localhost:3000` را باز کنید. در اولین اجرا، صفحه «راه‌اندازی اولیه»
نمایش داده می‌شود و شما نام کارگاه، نام مدیر و رمز عبور مدیر کل را تعیین می‌کنید.

### اجرای حالت توسعه (Hot Reload)

```bash
node scripts/dev-db.mjs          # ترمینال ۱ — پایگاه داده توسعه (پورت ۵۵۹۷)
# در server/.env این دو مقدار را تنظیم کنید:
#   PORT=3001
#   DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5597/repair_workshop
npm run dev:server               # ترمینال ۲ — API روی پورت ۳۰۰۱
npm run dev:client               # ترمینال ۳ — رابط کاربری روی پورت ۳۰۰۰
```

کلاینت توسعه درخواست‌های `/api` را به سرور پروکسی می‌کند؛ بنابراین کوکی و مبدأ یکسان است.

## آزمون‌ها

```bash
npm run typecheck                # بررسی نوع‌ها در سرور و کلاینت
npm run test:server              # ۳۵ تست یکپارچگی با PostgreSQL واقعی
npm run test:client              # ۹ تست واحد و DOM
node scripts/smoke-test.mjs      # ۲۱ بررسی HTTP روی سرور در حال اجرا (SMOKE_BASE)
```

> تست‌های سرور یک PostgreSQL موقت را روی پورت ۵۵۹۸ اجرا می‌کنند و به پایگاه داده بیرونی نیاز ندارند.
> `pg_dump` در محیط آزمایش با یک ابزار کنترل‌شده شبیه‌سازی می‌شود؛ روی سرور واقعی باید نصب باشد.

## ساختار پروژه

```
server/   سرویس مرکزی: API، احراز هویت، مجوزها، تاریخچه، پشتیبان‌گیری و مهاجرت‌های SQL
client/   رابط کاربری فارسی و راست‌چین
docs/     مستندات معماری، پایگاه داده، استقرار و گزارش مراحل
scripts/  ابزارهای توسعه و آزمون دود
```

## نکات امنیتی

- رمزها با bcrypt (هزینه ۱۲) ذخیره می‌شوند و هرگز بازگردانده نمی‌شوند.
- نشست‌ها با توکن تازه‌سازی چرخشی و کوکی `HttpOnly`/`SameSite=Strict` محافظت می‌شوند.
- تمام عملیات با بررسی مجوز نقش در سرور انجام می‌شود؛ پنهان‌کردن منو در کلاینت فقط برای تجربه کاربری است.
- هر ورود، تغییر کاربر، تغییر تنظیمات و پشتیبان‌گیری در تاریخچه ثبت می‌شود.
- پیش از بهره‌برداری، `JWT_SECRET` و رمز پایگاه داده را در `server/.env` تغییر دهید و فایل را از دسترس عمومی خارج نگه دارید.
